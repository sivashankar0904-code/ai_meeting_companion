- [x] Exe "not opening" (2026-10-26): root cause is the WSL VM that holds Postgres stopping when idle (not kept alive by running containers or by the app's own connection) and booting again 10-40 s after the next connection (seen at 10:36 wake from sleep, 10:38, 10:46). The old exe waited forever on that connect (no window, no output), and closing it while the VM was down hung for ~2 min. Fixed in source: 10 s `connect_timeout` + TCP keepalives, `open_store()` retries for 60 s with "Waiting for PostgreSQL..." in the log, shutdown DB steps capped at 20 s (`_bounded`). Needs an exe rebuild. Not fixed by code: the VM idling itself; keep WSL awake (`[wsl2] vmIdleTimeout=-1` in `%USERPROFILE%\.wslconfig` + `wsl --shutdown`, or a hidden `wsl -d Ubuntu --exec sleep infinity`). Workaround until rebuilt: run any `wsl` command first, wait ~30 s, then launch
