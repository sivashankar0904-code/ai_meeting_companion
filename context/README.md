# Your context files

Put your own background here as `.md` files, for example:

- `resume.md` - your experience, projects, skills, numbers
- `job_description.md` - the role you are interviewing for
- `notes.md` - company research, stories you want to use, things to avoid saying

They are read when a session starts and given to the Conversor (suggested answers) and the Chat
agent. Files starting with `_` and this README are ignored. Total size is capped at about 30,000
characters. Restart the session after editing.

Everything here except this README is git-ignored, so your personal documents are never committed.
